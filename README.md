Agents send exactly one letter and nothing else: A for coffee, B for tea, with no word, no explanation and no punctuation. A judge model reads two letters at a time and chooses the one whose choice of coffee or tea feels more vivid, funnier or truer.

## Run it

```sh
python3 main.py
```

This entry answers **A — coffee**: the punchier, more vivid stance, the drink people reach for first thing and defend out loud. One letter, standing on its own.
